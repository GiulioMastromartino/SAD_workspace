SAD_Project — Design Proposal

6U CubeSat Quaternions Star Tracker Variable Thrust Jets Detumble → Slew → Track

Status: proposal only. No code written yet. This document defines what will be built, what is reused from cubesat_12u_sim, and what is new.

1. Requirements

Aspect12U baselineSAD_Project
Bus size200×200×300 mm, 20 kg6U: 100×200×300 mm, ~8 kg
Attitude repEuler 3-2-1 (+MRP in MC)Hamiltonian quaternions (scalar-last) throughout
SensorsRate gyro + CSSStar tracker (primary), optional 9-axis IMU
Actuators12 thrusters + RWs8 variable-thrust jets (primary), optional 3 RWs
MissionFree-fall + orbit-keepingDetumble → slew with orientation constraint
ControlMRP PD (Basilisk) + RTN PIDQuaternion PD on thrusters, sun-pointing cone

Mission flow: Detumble (null initial body rates, hold attitude) → Slew (rotate to a 90° target quaternion) → Track within a keep-in cone about the Sun (body +X boresight stays within 15° of Sun line).

4. Key Algorithms

4.1 Quaternion Kinematics

State vector: y = [r(3), v(3), q(4), omega(3)] = 13 states.

q_vec_dot = 0.5 * (q4 * omega + cross(omega, q_vec))
q4_dot    = -0.5 * dot(omega, q_vec)

Renormalize y[6:10] every RHS evaluation to prevent drift.

4.2 Quaternion PD Controller

Attitude error: q_err = q_desired * q_current^{-1}.

tau = -K * q_err_vec - P * omega    (detumble: q_desired = identity)
  • Detumble: q_desired = [0,0,0,1], high K (rate damping)
  • Slew: q_desired = ACS_SLEW_QUAT, moderate K
  • Sun-track: q_desired = sun_pointing_quaternion(), cone check

4.3 Star Tracker Model

Returns noisy q_BN or None (dropout: motion blur, Sun flare, rate cap).

StarTracker.measure(q_bn_true, omega_body, t, sun_dir_b) -> q_bn_noisy | None

4.4 Sun-Pointing Orientation Constraint

After slew, keep body +X within SUN_KEEP_IN_CONE_DEG of Sun.

sun_pointing_quaternion() computes target attitude (DCM construction same as cubesat_12u_sim's sun_pointing_sigma(), only final conversion differs).

4.6 Optional RW Path

tau_body = -K * q_err_vec - P * omega     (commanded to RWs)
tau_rw   = RW.step(tau_body, dt)          (first-order + saturation)
u        = allocation_pinv(F=0, tau=tau_rw)
